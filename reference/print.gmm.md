# Print a Fitted Growth Mixture Model

Print a Fitted Growth Mixture Model

## Usage

``` r
# S3 method for class 'gmm'
print(x, ...)
```

## Arguments

- x:

  An object returned by
  [`fit_gmm()`](https://pdvalencia.github.io/mixtureEM/reference/fit_gmm.md).

- ...:

  Passed to the next method.

## Value

`x`, invisibly.
